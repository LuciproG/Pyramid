# Pyramid
A program that makes a mario-styled pyramid.
During Harvard CS50 week 1, one of the task was to make a program that recieves input from 1 to 8 to print a mario-styled pyramid for set height.
This program first asks the user for input and checks if the rquirements are met, an integer between 1 and 8, if said requirements are met, then the printing process starts. The first layer is the "height - row" number of blanks and "row number" of #, then two blanks and "row number" of #. The following layer continues the pattern.
